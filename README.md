# Diwali Sales Analysis — Python EDA Project

## Project Overview

This project explores Diwali sales data using Python to understand purchasing patterns, product category performance, and high-value purchase behavior. The analysis aims to convert raw data into meaningful business insights.

## Tools & Technologies

- Python
- Pandas and NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The dataset contains customer demographics, age groups, marital status, occupation, location, product categories, order information, and purchase amounts.

## Data Cleaning and Preparation

- Inspected the dataset structure, data types, and missing values.
- Removed columns containing no useful data.
- Handled missing purchase amount values.
- Identified and removed duplicate records.
- Prepared the data for exploratory data analysis.

## Business Questions

1. How are purchase records distributed by gender and age group?
2. Which age groups contribute the most to total purchase amount?
3. How do marital status and occupation relate to purchasing patterns?
4. Which states and zones contribute the most to sales?
5. Which product categories generate the highest total sales?
6. Which categories have the highest average purchase amount and order volume?
7. How are total sales, average purchase amount, and order volume distributed across categories?
8. What patterns can be observed in high-value purchase records?

## Key Findings

- The 26–35 age group contributes the highest total purchase amount in the analysis.
- Food generates approximately ₹3.39 crore in category sales.
- Clothing & Apparel has the highest order count in the category analysis.
- Auto has the highest average purchase amount among product categories.

## Business Recommendations

- Investigate the preferences of the 26–35 age group when planning targeted campaigns.
- Study the factors contributing to strong Food category sales.
- Explore opportunities to improve sales in lower-performing categories.
- Examine high-value purchase patterns to identify potential customer engagement opportunities.

## How to Run This Project

1. Download or clone this repository.
2. Keep the notebook and CSV dataset in the same folder.
3. Open `Python EDA Analysis Project.ipynb` in Jupyter Notebook.
4. Run the notebook cells from top to bottom.

This project demonstrates the use of Python for data cleaning, exploratory data analysis, visualization, and business insight generation. The findings can help explore purchasing patterns and inform data-driven business recommendations.
